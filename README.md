# simics-testdrive

Test drive of Intel Simics (public release, v7): a tiny I2C device written in
DML, operated by bare-metal C firmware on a simulated RISC-V board.

```
firmware (C, rv64) --MMIO--> toy_i2c_master --i2c-link-v2--> toy_i2c_slave (0x42)
```

- `modules/toy-i2c-slave/` – DML register-file slave: `0x00` WHO_AM_I (0xA5),
  `0x01` SCRATCH (rw), `0x02` COUNTER (increments per read), `0x03` LAST_WRITE.
- `modules/toy-i2c-master/` – DML polled MMIO master (DATA/CMD/STATUS at `0x10100000`).
- `firmware/` – bare-metal C (`riscv64-unknown-elf-gcc`) that reads/writes the slave and prints PASS/FAIL on the UART.
- `targets/testdrive.simics` – builds the machine (`risc-v-simple/bare-metal`), maps devices, wires the link, runs.

## Use

Open in the devcontainer (builds Simics into `/opt/simics`; image is large, ~10 GB), then:

```sh
scripts/run.sh                    # build modules + firmware, run, fail unless PASS
./simics targets/testdrive.simics # interactive (drop --batch-mode)
```

Raise `board.i2c_sensor.log-level` to see each bus transaction.

The Simics project scaffolding (`simics`, `GNUmakefile`, `.package-list`, ...) is generated by
`scripts/setup-project.sh` (run automatically on container create) and git-ignored.

Simics is downloaded from Intel's public URLs in `.devcontainer/Dockerfile`; by building the image you accept the Simics EULA.
